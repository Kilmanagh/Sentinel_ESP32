# Sentinel_ESP32

ESP Sentinel Project

## Repository contents
- `Sentinel_ESP32_Node.ino` - ESP32 node firmware source.
- `docs/Adjustments.MD` - tuning guide for PIR and sound sensors.
- `docs/Sentinel_ESP32_Node.md` - firmware usage/build notes.
- `docs/Hardware_Deliverables.md` - hardware package guidance.
- `hardware/schematics/` - schematic notes.
- `hardware/pcb/` - PCB and fabrication package folder.
